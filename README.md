# Щиты метро СПб в 3D

Карта Петербурга (MapLibre + OpenFreeMap, дома по этажности из OpenStreetMap), а под ней тоннель, пройденная часть и щит.

Сайт: https://rommmades.github.io/metro-shields/

## Как обновить положение щита

1. Откройте `data/shields.json` на GitHub и нажмите карандаш (Edit).
2. Поменяйте `"ring"` у нужного щита и `"updated"` (дата в формате ГГГГ-ММ-ДД). При желании добавьте строку в `history`.
3. Нажмите **Commit changes**. Через минуту сайт обновится.

## Устройство

- `index.html`, `style.css`, `app.js`: страница и 3D-слой (three.js r128 как custom layer MapLibre 4.7.1).
- `data/shields.json`: щиты. `"unit": "m"` показывает метры вместо колец. Трасса `path` задана в [долгота, широта], `ringKnots` сопоставляет номер кольца с долей пути (0…1), `stations` описывает станции в кольцах.
- `?offline` в адресе отключает подложку (для проверки без интернета), `?shield=<id>` открывает нужный щит.

Положение станций Каретная, Боровая и Заставская примерное.

## Трассы из OpenStreetMap

Добавьте строку `имя юг запад север восток` в `.github/osm-request.txt` и сохраните. GitHub Actions скачает линии и станции метро в этой рамке в `data/osm/<имя>.json`.
